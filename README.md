# Flagship Games brand reference, v0.2

Working guidelines prepared for owner review on 13 November 2026.

The original supplied logo and accepted paper/origami retail direction are preserved. Exact tokens, typography, clear space, templates and specimens are proposed refinements.

The supplied raster logo remains a Flagship Games asset; no official vector or print master is supplied. No blanket public licence is granted for the brand. Source Sans 3 and Barlow Condensed are distributed under the accompanying SIL Open Font License 1.1 files. Original abstract studies are design examples, not publisher artwork. Game names belong to their respective owners; no affiliation is implied.

The public reference application is published at https://squid-quarters.github.io/flagship-games-brand-guide/. The downloadable kit contains the written DESIGN.md specification, tokens, logo, fonts and templates. All website assets are local; there are no analytics or account integrations. Print guide on the website provides a print-friendly version for saving as PDF.

SVG templates use editable text fields and embed the unchanged PNG. Install the accompanying desktop fonts when editing. Replace every example field with confirmed details before publication. Screen colours are not press-ready CMYK specifications.
